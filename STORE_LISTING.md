# Chrome Web Store listing

## Name

Frame Screenshot → Clipboard

## Short description

Copy the current frame of any HTML5 video straight to your clipboard.

## Detailed description

Grab the exact video moment you need without creating a file.

Hover an HTML5 video, click the camera button, and the current frame is copied as a PNG. Paste it into ChatGPT, Slack, Figma, Docs, Notion, email, image editors, or anywhere else that accepts images.

### Features

- One click from the video player
- Toolbar shortcut for the largest visible video, including embedded players
- Custom one-key or two-key page shortcut (default: V then S)
- Native-resolution frame capture when the site allows it
- Automatic visible-frame fallback with nested iframe coordinate correction
- Detects looped “moving photos” implemented as HTML5 video
- Works with videos added dynamically by modern web apps
- Multiple videos per page
- No editor, save dialog, download, account, or tracking
- Fully local processing

### Privacy

Captured frames never leave your browser. The extension has no analytics, ads, telemetry, or remote code and does not collect browsing history or clipboard contents.

### Limitations

Some DRM-protected videos cannot be captured because the browser intentionally blocks access to their decoded frames.
