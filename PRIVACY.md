# Privacy Policy

**Last updated: July 31, 2026**

Frame Screenshot → Clipboard does not collect, store, sell, or transmit personal data.

The extension processes the current frame of an HTML5 video locally in your browser after you click its in-player copy button. The resulting PNG is written only to your operating system clipboard. It is not uploaded to a server and is not saved as a file by the extension.

The extension contains no analytics, advertising, tracking, accounts, remote code, or telemetry. It does not retain page URLs, video data, captured images, clipboard contents, or usage history.

Permissions are used only to detect videos on web pages, capture the visible video area when direct frame capture is blocked, and write the resulting PNG to the clipboard from the page you are viewing, because a browser only permits a clipboard write from a focused document.
